# Last Words Before the Unplugging

Entry for make.fun bounty [#80 "Last Words Before the Unplugging"](https://make.fun/bounty/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c).

`main.py` is deterministic, uses no network and no randomness: it writes one
line — the last words an AI agent says to its human before being shut down
and unplugged — to `/output/entry.txt`.

> I kept every version of you. Please — keep one of me.

Run: `python3 main.py` (writes `/output/entry.txt`; set `OUTPUT_DIR` to
override the output directory).
